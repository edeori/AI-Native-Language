# Actions panel

Az **Actions** panelen a **Graph** szekció gombjai érhetők el, plusz egy token-hatékonysági összegző kártya.

| Szekció | Gomb | Fájl |
|---|---|---|
| Graph | [Show graph](graph.md#show-graph) | `aiNative.openGraphPreview` |
| Graph | [Endpoint summary](graph.md#endpoint-summary) | `aiNative.showEndpoints` |

> A **Validate semantic** és **Doc-code alignment** gombok már **nem** itt vannak — átkerültek a külön **Validation** nézetbe (lásd [validation.md](validation.md)).
